# Project Management Sync

Use this skill to synchronize your local `.agent-config/tasks.json` with external project management tools.

## Commands

- `/sync`: Run bidirectional sync (Pull + Push).
- `/sync-pull`: Pull remote tickets into your local `tasks.json`.
- `/sync-push`: Push local changes to the remote PM tool.
- `/sync-status`: Check the status of the sync engine.

You can also ask me to "sync my tasks" or "pull from Jira".
